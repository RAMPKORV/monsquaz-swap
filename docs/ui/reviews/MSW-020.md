# MSW-020 UI review record

Scope: event setup wizard, participant manager, schedule planner, and the
redaction preview. The shell, settings, audit log, and mission control were
re-captured because the design system and shared components changed.

Build: production UI build with deterministic preview data (`VITE_DEMO=1`).
Screenshots: `docs/ui/screens/`. Capture: `docs/ui/capture.sh`.

The visual wave ran three rounds against the rendered screenshots. The UX/copy
and accessibility waves ran two rounds each against the same capture set and
the source. Every must-fix was fixed before the next round. No must-fix item
remained in the final round of each wave.

## Wave 1 — Visual design

Reviewer: independent agent with no memory of the implementation. The reviewer
inspected the rendered screenshots and the CSS, and returned a verdict and a
severity-ranked list.

Verdict: no significant defects remained.

## Wave 3 — Accessibility

Reviewer: independent agent with no memory of the implementation. Checked
WCAG 2.2 AA, focus order, semantics, contrast, keyboard paths, and the 1024 px
minimum.

### Round 1

| # | Element | Severity | Finding | Resolution |
|---|---|---|---|---|
| 1 | Palette search | must-fix | The auto-focused input had `outline: 0` and no focus ring. | The search row has a `:focus-within` accent ring. |
| 2 | Palette dialog | must-fix | Tab left the modal and closing did not restore focus. | Tab is trapped in the palette; the previous focus is restored on close. |
| 3 | Palette listbox | must-fix | The combobox relationship was missing and Enter could run a different option than the focused one. | The input is a combobox with `aria-activedescendant`; options have ids, `aria-selected`, `tabIndex=-1`, and focus syncs the active option. |
| 4 | Raised small text | must-fix | `--faint` on `--surface-2` measured 4.10:1. | Raised contexts use `--faint-raised`; measured 5.39:1 dark and 5.22:1 light. |
| 5 | Event setup fields | must-fix | Help text was visible but not associated with the inputs. | Every Setup field with help has a `helpId` and `aria-describedby`. |
| 6 | Primary hover | should-fix | White on the hover fill measured 3.87:1. | The hover fill is `#405cf0` (5.24:1). |
| 7 | Delivery-risk mark | should-fix | The alert icon relied on a hover title. | The mark includes visually hidden "Delivery risk" text. |
| 8 | Graph edges | should-fix | Edge and node strokes measured 1.78:1. | Edges and nodes use `--faint` (4.55:1 dark, 5.15:1 light). |
| 9 | Theme cards | should-fix | Unselected card borders measured about 1.3:1. | Unselected cards use `--field-line` (3.39:1 dark, 3.31:1 light). |
| 10 | Scrollbars and dense tables | should-fix | The scrollbar thumb measured 1.78:1 and the dense audit had no visible cue. | The thumb uses `--faint`; the filter count says "scroll for more". |
| 11 | Toasts | should-fix | Error toasts disappeared after 8 seconds. | Error and blocked-notification toasts persist until dismissed. |
| 12 | Settings save bar | should-fix | The unsaved state was not announced. | The save-bar copy is a status region. |
| 13 | Graph description | should-fix | The SVG description described the layout but not the data. | The description points to the assignment matrix. |

### Rounds 2–4

| Round | Element | Severity | Finding | Resolution |
|---|---|---|---|---|
| 2 | Async actions and reloads | must-fix | Focus fell to the document body when the save bar, a row, or the view was replaced. | Save, reset, toast close, and every reload hand focus to the view heading. The save control stays mounted while saving. |
| 2 | Event setup steps | must-fix | Continue and Back changed the step without announcing it. | Step changes focus the step heading, which has a visible focus ring. |
| 2 | Claim and round fields | should-fix | The visible "hours" unit was not in the help text. | Both help strings include the unit. |
| 2 | Toasts | should-fix | Success toasts still expired after 8 seconds. | All toasts persist until dismissed. |
| 2 | Command palette and dialogs | should-fix | Ctrl+K could open the palette behind a lock or delete dialog. | Ctrl+K is ignored while any non-palette modal is open; a test covers the lock dialog. |
| 2 | Palette empty state | should-fix | The empty message was a bare list item inside the listbox. | It is a status paragraph outside the listbox. |
| 2 | Theme cards | should-fix | Hover lowered the card border contrast. | Hover keeps the field-line border. |
| 3 | Settings save/reset | must-fix | The savebar unmounted while its Save or Discard button held focus. | Both actions move focus to the view heading after the state change. |
| 3 | Full-page error | should-fix | The error state had no h1 and did not move focus after a failed reload. | The error panel uses an h1 and receives focus. |
| 3 | People filtered row | should-fix | A paused row could disappear while its action held focus. | Demo mode moves focus to the status filter; live mode focuses the view heading after reload. |
| 3 | Risk mark wording | should-fix | The visible summary said "Message failure" while the hidden row label said "Delivery risk". | The hidden label matches. |

Round 4 verdict: no must-fix item remained.
