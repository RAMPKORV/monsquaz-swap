# UI review — MSW-059 group lookup and warnings

Review date: 2026-11-26. Build: MSW-059 worktree.

Screenshots: `docs/ui/screens/setup-groups-scales-1280.png`,
`setup-groups-scales-1024.png`, and `setup-review-scales-1024.png`.

## Scope

- The group lookup derives the count and size from the active roster when the
  planner generates a plan.
- The plan stores the effective count and size.
- The manual group count and size controls are enabled only for the Manual
  group mode.
- Soft-bound and cadence warnings appear in the planner and do not block.
- The setup Review step shows "Lookup at lock" instead of a misleading fixed
  count and size.

- `scripts/design-check.sh`: pass, 0 locked findings, 0 baseline entries. The
  matrix now includes the setup Groups step and covers 27 pages.
- `scripts/check.sh`: tracker, UI, design, and Rust pass.

- `cargo test -p swap-core groups`: 5 pass.

## Wave 1 — Visual design

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Groups, Review | Focused step title | must-fix | The 2px accent ring around the programmatic step title looked like a focused text input. | The title uses a 3px left accent bar instead. The title no longer looks like an input. |
| Groups | Lookup | should-fix | The disabled fields looked like empty editable inputs and repeated the helper copy three times. | The fields have a gray surface, a softer border, and placeholders. The field helpers are one short line. The select helper keeps the Manual override. |

| Review | 1024 | nit | The invite preview and primary action sit below the fold. | Pre-existing and recorded in the MSW-055 review. |

No must-fix remained after the fixes.

## Wave 2 — UX and copy

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Groups | Lookup | must-fix | The disabled fields showed 2 and 6, so the stored values looked like the plan. | The fields are empty with "From roster" placeholders. The helper says the planner sets the values from the locked roster. |

| Review | Lookup | must-fix | "Lookup at lock" introduced a third name for the mode. | The option, helper, and Review row now use "From the locked roster". |

| Groups | Lookup, Single, Manual | should-fix | The Group suggestion help was static. | The help branches by mode and explains the override. |

No must-fix remained after the fixes.

## Wave 3 — Accessibility

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Groups | Lookup | should-fix | The disabled field text was faint and the dark-theme value was below 4.5:1. | The disabled value and placeholder use `--faint-raised` (about 5.2:1 light and 5.4:1 dark). |
| Groups | Lookup | should-fix | The disabled values did not say they were inactive. | The placeholders and helpers state that the planner sets them from the locked roster. |
| Setup steps | All | should-fix | The ordered list lost list semantics in WebKit and completed steps were silent. | The list has `role="list"` and completed steps have a visually hidden "Completed" label. |
| Groups | Callout | nit | The callout heading was h2 at the same level as the step title. | It is h3 and shares the note-card heading style. |

No must-fix. Labels remain associated, disabled fields stay out of the tab
order, targets are 32 px or larger, and there is no overflow or clipping at
1024 or 1280.

## Verdict

No must-fix remained after the fixes. The visual reviewer re-checked the step
title bar and the disabled fields and reported "ship". The UX and
accessibility reviewers confirmed their must-fix and should-fix items were
resolved. The remaining nits are accepted or recorded. MSW-059 is safe to
merge.
