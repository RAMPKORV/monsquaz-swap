# UI review — MSW-050 reveal presenter

Review date: 2026-11-26. Build: MSW-050 worktree.

Screenshots: `docs/ui/screens/reveal-*.png`.

## Scope

- Host-only reveal presenter: ordered album, lineage, R1/final audio, credits,
  comments, stats, and the read-only published state.
- Stream-safe mode: default on, persistence, confirmation before names show.
- Publish reveal and redact-comment dialogs.
- Titles and comments before publish.
- The opaque audio preview protocol.
- The deterministic design gate (`design/`, `scripts/design-check.sh`).

## Wave 1 — Visual design

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Album card | Long event name | must-fix | The album heading collapsed and the event name overflowed the card. | The album meta is now only the track count. The detail title wraps. |
| Album card | Dense, 1024 | must-fix | The sticky 12-track album exceeded the scrollport. | The album list has a bounded internal scroll area. |
| Loading | All | must-fix | The skeleton was blank because its nodes had no size. | The view uses sized `Skeleton` components and a status label. |
| Header and tools | Populated | must-fix | Publish, Save title, and stream-safe competed as primary actions. | Publish is the only primary. Save title and stream-safe are secondary. |
| Listen, lineage, credits, comments | Dark | should-fix | Faint metadata and the Fill-in badge were below AA on raised surfaces. | Faint text uses `--faint-raised`; the badge uses `--accent`. |
| Lineage | All | nit | The second version dot looked disabled. | Removed the arbitrary grey dot. Gaps use a hollow dot. |
| Header actions | 1024 | nit | The actions wrapped into three rows. | The header stacks and the actions share one row. |

No must-fix remained after the fixes. The reviewer re-checked the four must-fix
items and reported no must-fix.

## Wave 2 — UX and copy

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Publish dialog | Blocked | must-fix | A blocked publish closed the dialog and announced success. | The publish call returns a result. The dialog stays open, lists the blocking tracks, and announces the block. |
| Stream-safe | All | must-fix | Mode started off and was lost on navigation. | It defaults on, lives in App state, persists in `sessionStorage`, and turning it off needs confirmation. |
| Stream-safe | Not published | must-fix | The note said host tools were hidden while Publish stayed visible. | The note says publishing stays available. Editing tools are hidden. |
| Stream-safe | Published | must-fix | The pre-publish warning told the host to hide the payoff after the reveal. | Published copy says the reveal is public. Safe mode explains that it hides the public credits. |
| Loading | All | must-fix | The view was blank and silent. | Sized skeleton, status role, hidden loading text, and a focus target. |
| Album | Long | must-fix | The event name dominated the album header. | Removed from the album card. The top bar keeps the event name. |
| Lineage | Gap | must-fix | A skipped round vanished from the lineage. | Added an anonymous `Gap · no edit` row per skipped round. |
| Stream-safe | All | must-fix | Role labels were inconsistent between Listen, Lineage, Credits, and Comments. | One role mapping: Seed owner, Editor N, Participant N. |
| Host tools | Add comment | must-fix | Author and kind had no visible labels. | Visible Author and Kind labels, a fieldset legend, and character hints. |
| Evidence | All | must-fix | No published, gap, blocked, 1024 dialog, or dense 1024 capture. | The capture matrix now includes these states. |

No must-fix remained after the fixes. The reviewer re-checked the items and
reported one published-copy issue, which is now fixed.

## Wave 3 — Accessibility

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Header | All | must-fix | `aria-pressed` was dropped by the Button component. | Button forwards `aria-pressed`. Stream-safe has a stable name and a hidden description. |
| Publish dialog | Blocked | must-fix | A blocked publish announced a false success. | The block stays in the dialog with `role="alert"`; success is announced only on publish. |
| Loading | All | must-fix | The skeleton had no size, status, or focus target. | Sized skeletons, `role="status"`, hidden loading text, and a focusable h1. |
| Reveal view | 30 s poll | must-fix | Polling set global loading and unmounted the view, losing focus and form state. | The reveal poll refreshes only the package. It does not change page status. |
| Dialogs | Success | must-fix | Focus was restored to a removed trigger. | Dialog restores focus only when the trigger is connected; otherwise it focuses `#main h1`. |
| Album | Long | must-fix | The album heading was unreadable. | Fixed with the album meta change. |
| Audio note | Dark | must-fix | The preview note was 4.10:1 at 10.5 px. | It uses `--faint-raised` (5.39:1). The design gate reports 0 locked contrast findings. |
| Redact buttons | Comments | should-fix | Every button was named “Redact”. | Each name includes the author. |
| Dialog | All | should-fix | Tab could escape after clicking dialog text; background scrolled. | The trap redirects escaped focus. The dialog locks body scroll. |
| Empty | All | should-fix | The empty state had no h1. | The view uses PageHeader and an Event setup action. |
| Audio | All | should-fix | Audio labels omitted version and holder; errors were not live. | Descriptive names, described-by note, and `role="alert"` on errors. |
| Lists | All | should-fix | `list-style: none` can remove semantics in Safari. | Album, lineage, credits, and comments use `role="list"`. |
| Evidence | All | should-fix | The capture script had no reveal matrix. | `docs/ui/capture.sh` captures the full reveal matrix. |

No must-fix remained after the fixes. The reviewer re-checked the seven
must-fix items and reported the audio note contrast, which is now fixed.

## Adversarial review

| Area | Severity | Problem | Resolution |
|---|---|---|---|
| Stream-safe | must-fix | Mode started off and turned off with one click. | Default on, persisted, confirmation before disabling. |
| Titles/comments | must-fix | State could change between the check and the write. | `open_event_in` rechecks inside the transaction. |
| Reveal text | must-fix | A title or comment could inject mentions or extra lines. | Control characters are replaced, mentions are neutralized, and the HTTP adapter sends empty `allowed_mentions`. |
| Preview | must-fix | File IDs were predictable and not event-scoped. | Per-process 128-bit tokens; the protocol requires the current event. |
| ADR | should-fix | The rollback note claimed an older build ignores the schema. | It now states `SchemaTooNew` and backup restore. |
| Privacy export | should-fix | Comments and title authorship were omitted. | The participant export includes both. |
| Audit | should-fix | Redaction recorded only the track code. | It records the comment id. |
| Title fallback | should-fix | The automatic previous-submitter fallback is not implemented. | The host sets the title. The feature file and ADR state the deferral. |

The adversarial reviewer re-checked the four must-fix items and reported no
must-fix with a merge verdict.

## Deterministic design gate

`scripts/design-check.sh` renders 22 pages at 1280×800, 1024×700, and
640×400 with the pinned Refract commit. It also checks WCAG AA text contrast
and visible keyboard focus with Playwright, and it checks the CSS policy in
`design/policy.json`.

- Locked and passing: no raw colors outside tokens, no layout `!important`,
  contrast, focus, no horizontal overflow, no clipping, no hard text overflow,
  and the viewport meta.
- Baseline: zero locked findings.
- Advisory: 130 spacing-scale, 13 type-scale, and 2 radius-scale findings.
  These scales are not locked. Agents can fix them or change the advisory
  rules. See `ai-rules/DESIGN.md`.
