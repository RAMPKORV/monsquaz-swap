# UI review — MSW-048 join instructions and message catalog

Review date: 2026-11-26. Build: MSW-048 worktree.

Screenshots: `docs/ui/screens/mission-join-*` and
`docs/ui/screens/setup-review-*`.

## Scope

- A small message catalog with `format`, `plural`, `formatDateTime`, and
  `joinInstructions`.
- A copyable join-instruction block in mission control during the join phase.
- A draft preview of the same block in the setup review.
- The participant DM example and the host copy text.
- The design gate covers the join phase and the setup review.

## Copy and DM evidence

Host copy text:

```text
Join the swap:
1. In the server, run /swap join.
2. Choose your timezone (for example Europe/Stockholm) and max_handoffs (the number of tracks you will edit, 1 to 20).
3. Send one seed file to the bot in a direct message. A seed is a track you made.
Allowed formats: .it, .mptm, .xm, .mod, .s3m, .mtm, .669, .wav, .flac, .mp3, .ogg, .zip
Maximum size: 20 MiB.
The host starts the event after the roster locks.
```

Participant DM example:

```text
You are signed up. Send one seed file (.it, .mptm, .xm, .mod, .s3m, .mtm, .669, .wav, .flac, .mp3, .ogg, .zip) no larger than 20 MiB to this direct message. A seed is a track you made. The host starts the event after the roster locks.
```

The message catalog is `ui/src/i18n.ts`. It exposes `format`, `plural`,
`formatDateTime`, and `joinInstructions`. The tests cover values, plurals,
timezone formatting, and the full copied text. The agent rule for future
translation work is to keep sentences in the catalog, not in components.

## Deterministic design gate

The gate renders 26 pages at 1280×800, 1024×700, and 640×400. The join phase
and setup review are in the matrix. It reports 0 locked findings. The advisory
scale findings remain: 138 spacing, 14 type, and 2 radius. See
`ai-rules/DESIGN.md`.
