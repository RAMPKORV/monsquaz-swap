# UI review — MSW-058 long-title topbar

Review date: 2026-11-26. Build: MSW-058 worktree.

Screenshots: `docs/ui/screens/reveal-long-dark-1280.png` and
`reveal-long-dark-1024.png`.

## Scope

- A long event name must not wrap or compress the topbar actions.
- The event name truncates and exposes the full name in a title.
- Below 1100 px the command trigger is icon-only.
- The controls keep a 28 px or larger target.

## Automated evidence

- `pnpm --dir ui test`: 50 pass, including the full-name title test.
- `scripts/design-check.sh`: pass, 0 locked findings.
- `scripts/check.sh`: tracker, UI, design, and Rust pass.

## Wave 1 — Visual design

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Topbar | 1024 | must-fix | The trigger kept the Ctrl K chip, so it read as two controls and contradicted the icon-only rule. | At <=1100 px both the label and the kbd hide; the trigger is one 30x28 icon with title and aria-keyshortcuts. |
| Topbar | 1024 | should-fix | The fixture did not truncate, so the ellipsis was unproven. | The long fixture is about 115 characters and truncates before the actions at 1024. |
| Topbar | 1024 | nit | The event name starts 4 px right of the page heading. | Accepted for v1. |
| Album | 1024 | nit | Selected titles truncate with spare width. | The row has a full-title title attribute. |

No must-fix remained after the re-capture.

## Wave 2 — UX and copy

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Topbar | 1024 | must-fix | The icon-only Jump to control had no visible shortcut cue. | The Ctrl K keycap stays visible; only the words "Jump to" hide. The button has a title and `aria-keyshortcuts`. |
| Topbar | 1024 | should-fix | "Preview data" read like a ghost button. | It is a borderless "Demo data" tag with a sample-data title. |
| Album | 1024 | should-fix | Truncated track titles had no full-name affordance. | Each album row has the full title in `title`. |
| Reveal, audio | Both | should-fix | Demo mode has no audio player and the copy is circular. | Outside MSW-058; recorded as a follow-up. |
| Reveal, stream-safe | Both | should-fix | The label mixes state and action wording. | Outside MSW-058; recorded as a follow-up. |

No must-fix remains. The 74-character fixture fits at 1024, so the ellipsis path
is covered by the title test rather than the capture. A longer fixture can be a
later evidence improvement.

## Wave 3 — Accessibility

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Topbar | 1024 | should-fix | The icon-only Jump to button had no visible name for mouse users. | The button has `title="Jump to (Ctrl K)"`; the accessible name stays "Jump to". |
| Album | 1024 | should-fix | Long album titles truncate and the row had no full-name affordance. | Each album row has the full title in `title`. |

No must-fix. The Preview data pill is still visible at 1024; the earlier report
that the media query hid it was a false positive. The topbar targets are 28 px,
which passes WCAG 2.5.8. The gate passes contrast, focus, overflow, and
clipping.

## Verdict

No must-fix remains after the fixes and re-capture. The visual, UX/copy, and
accessibility reviewers confirmed the icon-only trigger, the full-name title,
and the truncation path. MSW-058 is safe to merge.

Pre-existing follow-ups outside this issue: the demo audio placeholder copy,
the stream-safe state/action wording, and the album title clamp at 1024.
