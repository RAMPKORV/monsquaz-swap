# MSW-042 UI review record

Scope: seeded schedule matrix and graph, draft, dense, long, infeasible, and
participant redaction states at 1280, 1024, light, and 200% zoom.

Build: production UI build with deterministic preview data (`VITE_DEMO=1`).
Screenshots: `docs/ui/screens/`. Capture: `docs/ui/capture.sh`.

The visual wave ran three rounds. The UX/copy and accessibility waves ran two
rounds each. Every must-fix was fixed before the next round. No must-fix item
remained in the final round of each wave.

## Wave 1 — Visual design

Reviewer: independent agent with no memory of the implementation.

### Round 1

| # | View | Severity | Finding | Resolution |
|---|---|---|---|---|
| 1 | Schedule planner, dense | must-fix | The 40-track matrix had a bounded vertical scroll inside the page scroll, which cut a row at the card edge and trapped scrolling. | The matrix grows with the page. Only horizontal overflow remains. |
| 2 | Schedule planner, 200% | must-fix | The horizontal sidebar hid the active Schedule item and offered no overflow cue. | The sidebar wraps to two rows below 900px. The active item keeps an accent underline. |
| 3 | Schedule planner | should-fix | Matrix names, headers, and group tags were 9.5–11px. | Names are 12px, headers 11px, and group tags 10.5px. |
| 4 | Schedule planner | should-fix | The group letter had no legend. | The matrix subtitle explains the owner-group letter and states the no-repeat and no-own-track guarantees. |
| 5 | Schedule planner, infeasible | should-fix | The banner named blocked tracks but the matrix did not mark them. | Tracked as a follow-up; the warning still names the tracks. |
| 6 | Schedule planner | should-fix | Warnings were below the graph and the info note read “1 to review”. | The action bar shows the warning count beside Draft. Info notes read “1 note”. |
| 7 | Schedule planner, participant | should-fix | The redaction notice was one long line and the participant matrix was mostly dashes. | The notice is shorter with a meta line. Matrix density remains a follow-up. |
| 8 | Schedule planner, graph | should-fix | Graph labels scaled with the card and the rail beside it was empty. | Tracked as a follow-up. |
| 9 | Schedule planner, 200% | should-fix | The summary stacked four full-width rows. | The summary is a 2×2 grid at 640px. |
| 10 | Schedule planner, 200% | should-fix | The bot state disappeared with the sidebar footer. | The status bar shows Bot online/offline below 900px. |

## Wave 3 — Accessibility

Reviewer: independent agent with no memory of the implementation.

### Round 1

| # | Element | Severity | Finding | Resolution |
|---|---|---|---|---|
| 1 | Planner evidence | must-fix | Four planner captures showed the global service-error panel. | Recaptured. The capture script fails on that panel and checks the planner or redaction heading. |
| 2 | Graph | should-fix | `graph-title` was used by the card heading and the SVG title. | The SVG uses `graph-figure-title` and `graph-figure-desc`. |
| 3 | Matrix scroller | should-fix | A generic focusable div carried an `aria-label`. | It is a named group with a described keyboard help. |
| 4 | Participant matrix | should-fix | Blank cells exposed only an em dash. | They include visually hidden “No assignment”. |
| 5 | Warning severity | should-fix | Severity relied on colour. | Each warning has a distinct icon and a visually hidden severity word. |
| 6 | Full names | should-fix | Full names were available only through `title`. | Matrix cells and graph labels include the full name for assistive technology. |

### Round 2

Verdict: no must-fix remained. Final score: 9/10.
