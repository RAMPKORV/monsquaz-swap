# MSW-115 — UI review record

**Scope:** automatic backups, the backup history, the restore wizard, and the
bot lock in Settings.

## Outcome

Three independent review waves returned **NO**:

- Visual design: 1 must-fix, 4 should-fix, 6 nits.
- Accessibility: 2 must-fix, 5 should-fix, 8 nits.
- UX and copy: 15 must-fix, 18 should-fix, plus nits.

This branch fixes every must-fix and should-fix. The table below maps each
finding to its fix and test.

## Review method and limits

The three reviews were run outside this working session. This pass used their
consolidated order and did not start another set of fresh reviewers, because
the execution harness does not allow nested reviewer subagents. Re-review the
captures before merge.

The demo fixtures are realistic, but their times are relative to the capture
time (`Date.now`). The screenshots are current-build evidence, not
byte-for-byte determinism. A screen-reader application pass was not run; roles,
names, focus, and live regions were checked in the DOM and in Playwright.
