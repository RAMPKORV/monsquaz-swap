# MSW-053, MSW-064, MSW-065 — UI review record

**Scope:** async queue length, coverage, gap report, two-wave release, Ready
gate, host overview, and participant season surface.

## Captures

- `mission-async-*` — host queue overview, target math, exposed pairs, gaps,
  next wave, dispatch action.
- `setup-review-*` — expected songs, claims target, release time, late seeds.
- Existing async and channel screens reused where unchanged.

## Wave 1 — visual design

Must-fixes found and resolved:

- The gap total was trailing text and the reasons were unlabeled numbers.
  **Fixed:** a separate gap block with the total, labeled reasons, and a
  collapsible gap list.
- The queue action floated between blocks. **Fixed:** the action sits on the
  release row; the gap block has its own rule.
- The setup review duplicated the round window and the round deadline.
  **Fixed:** one deadline row for classic and one edit row for async.
- The setup footer overlapped the invite preview at 1024. **Fixed:** the join
  preview is collapsed under "Join copy preview"; the footer stays in flow.
- Event facts repeated the queue card under async. **Fixed:** async facts show
  only configuration that the card does not.

## Wave 2 — UX and copy

Must-fixes found and resolved:

- The host target math was unclear. **Fixed:** the card shows planned songs,
  claims, editors per track, and exposed pairs.
- Gap reasons now say "not offered", "expired", "handoff cap", and "skipped
  before claim" with counts.
- The empty state said "The round is healthy" on a no-round screen.
  **Fixed:** "The queue is healthy."
- The next wave line now names the wave, the local time, and the IANA zone.
- The async start action is explicit: "Start async queue". The queue does not
  start from a timer.

## Wave 3 — accessibility

Must-fixes found and resolved:

- The gap block is a named group with a heading and a list.
- The gap list is collapsible and keeps the summary focusable.
- The release time and next wave are text, not color-only.
- The async card has a heading and the queue rule is in text.
- Setup fields keep their help links and labels.

**Remaining note:** the 1024 mission layout reflows the right rail below the
queue card. The facts remain reachable by scroll.
