# UI review — MSW-055 design scales

Review date: 2026-11-26. Build: MSW-055 worktree.

Screenshots: `docs/ui/screens/*-scales-*.png` and the full Refract matrix in
`design/artifacts/refract/<page>/<viewport>.png`.

## Scope

- Snap every spacing, font-size, and border-radius value to the design scales.
- Remove the off-scale radius tokens. Keep one small radius token at 4 px.
- Lock the spacing, type, and radius scales in `design/policy.json`.
- Record the contract change in decision D-029 and ADR 0006.
- Keep the visual hierarchy and every enforced viewport intact.

## Scale mapping

| Scale | Allowed values (px) |
|---|---|
| Spacing | 0, 2, 4, 6, 8, 12, 16, 20, 24, 32, 40, 48, 64 |
| Type | 10, 10.5, 11, 11.5, 12, 13, 14, 16, 18, 20, 24, 30, 44 |
| Radius | 0, 4, 6, 8, 12, 16, 999 |

Off-scale values were snapped to the nearest allowed value. Tight spacing
rounded down where expansion would risk overflow. The old 2 and 3 px radii
became 4 px. The 5 px radius became 6 px. The 7 px radius became 8 px. The
`--radius-xs` token was removed because it mapped to the same value as
`--radius-sm`.

Negative margin hacks were replaced with zero. The visually hidden helper and
the toast close button keep their layout without negative margins.

## Automated evidence

- `scripts/design-check.sh`: 0 locked findings, 0 advisory scale findings, and
  0 baseline entries. All 26 pages render at 1280x800, 1024x700, and 640x400.
- `scripts/check.sh`: tracker, UI, design, and Rust pass.
- The design gate checks contrast, visible focus, horizontal overflow,
  clipping, text overflow, raw colors, `!important`, and the three locked
  scales.
- Manual DOM checks: the planner matrix has 1 tab stop across 320 cells. The
  review-step focus ring is inset by 2 px. The bot-token summary target is
  24.5 px high. The disabled label contrast is about 4.66:1.

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|

No must-fix. Mission control and the Settings bot dialog had no findings.
There was no radius or typography breakage and no dark/light inconsistency.

## Wave 3 — Accessibility

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Event setup | Review step focused, 1024x700 | must-fix | The 2 px global focus ring with a 2 px offset was clipped by the horizontally scrolling stepper. | The stepper tabs use an inset ring: `outline-offset: -2px` and a 4 px radius. The computed offset is -2 px and the full ring is visible. |
| Settings | Bot dialog, default | must-fix | "How to create a bot token" was a 16.5 px target. | The summary has 4 px block padding. The computed target height is 24.5 px. |
| Settings | Disabled actions | should-fix | The 0.42 opacity made disabled labels hard to read. | The disabled opacity is 0.6. Disabled text stays WCAG-exempt. |
| Schedule planner | Dense matrix | should-fix | Reported as 320 matrix tab stops. | False positive. The matrix uses a roving tabindex: exactly 1 of 320 cells has `tabindex="0"` and 319 have `tabindex="-1"`. Arrow keys move focus, and a UI test covers the path. |
| Reveal show | Long event name, 1024x700 | should-fix | The top bar actions wrap. | Pre-existing. Recorded in wave 1 and wave 2 as a follow-up. |

The automated gate already passes contrast, visible focus, overflow, and
clipping. The 10 px type is limited to non-essential metadata. The album and
matrix focus rings are intact.

## Verdict

No must-fix remained after the fixes. The accessibility reviewer re-checked
both must-fix items and withdrew the matrix tab-stop finding. The visual and
UX reviewers found no must-fix from the scale change. The remaining
should-fix and nits predate MSW-055 and are recorded above as follow-ups. The
scale cleanup is safe to merge.
