# UI review — MSW-049 deadline decisions

Review date: 2026-11-26. Build: MSW-049 worktree.
Screenshots: `docs/ui/screens/mission-*-decision-*.png` and
`mission-deadline-confirm-missed-*.png`.

## Scope

- Overdue deadline decision card and dialog.
- Second-step confirmation for a missed turn.
- Extension request card and dialog.
- 1280×800, 1024×700, light and dark themes, and 200% zoom.

## Wave 1 — Visual design

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Deadline dialog | Default | should-fix | “Keep waiting” looked like body text. | It uses the secondary button style. |
| Decisions row | 1024 | should-fix | The detail column grew a widow and pressed against the meta column. | The copy is shorter; the row wraps cleanly at 1024. |
| Both dialogs | Default | nit | The consequence lacked the deadline. | Added current and new deadline meta lines. |
| Extension dialog | Light | nit | The scrim weight differs from dark. | Accepted; the shared dialog scrim is unchanged. |

No must-fix remained after the fixes. The dialog width, footer alignment, contrast,
and button rows pass at both widths and themes.

## Wave 2 — UX and copy

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Deadline dialog | Default | must-fix | The dialog repeated state but not the result of each action. | Shows the current deadline, new deadline, extension count, DM, seen, pool, and “cannot be undone” consequences. |
| Deadline dialog | Destructive | must-fix | “Mark missed” was a one-click irreversible action. | Added a second dialog with the seen, pool, notification, and irreversible consequences. |
| Deadline dialog | Copy | must-fix | Body and buttons used different terms. | Both use “Extend”, “Mark turn missed”, and “Keep waiting”. |
| Extension dialog | Default | must-fix | The fixture showed a first request that the engine auto-approves. | The fixture is the second request with 1 of 2 extensions used. |
| Extension dialog | Default | must-fix | Approve and refuse did not show the new deadline or limit. | Shows current and new deadline, the extension count, and notification. |
| Deadline dialog | Default | should-fix | The holder was unnamed and the no-auto-advance promise was absent. | Names the holder and says “Nothing has moved.” |
| Deadline dialog | Extension cap | should-fix | Extend stayed enabled at the cap. | Extend is disabled and reads “Extension limit reached” at 2 of 2. |
| Both | Copy | should-fix | “six” and “6” and “S7F3A” and “Track S7F3A” drifted. | Copy uses “6” and “Track S7F3A” consistently. |

No must-fix remained after the fixes. The next action is clear and the safe
default is Cancel.

## Wave 3 — Accessibility

| View | State | Severity | Problem | Resolution |
|---|---|---|---|---|
| Deadline dialog | Confirmation | must-fix | Focus dropped to the body when the review step became the confirmation step. | The dialog is keyed on the step, so it remounts and focuses Cancel. A UI test asserts the focus. |
| Mission | Review decisions | should-fix | Focus stayed on the button after the page scrolled. | The decisions heading has `tabIndex=-1` and receives focus. |
| Deadline dialog | Destructive | should-fix | The danger action sat next to the primary action. | The danger action has extra spacing from the primary. |
| Both dialogs | Default | should-fix | The consequence was not linked to the dialog title. | The shared dialog sets `aria-describedby`. |
| Shared dialog | All | nit | Background content can scroll under the modal. | Accepted for v1; the existing dialog pattern is unchanged. |
| Shared dialog | All | nit | The focus trap omits custom tabindex elements. | Accepted; no such elements are used. |

No must-fix remained after the fixes. Focus order, Escape, focus restore,
button order, touch targets, contrast, 1024 width, and 200% zoom pass. No status
uses colour alone.
