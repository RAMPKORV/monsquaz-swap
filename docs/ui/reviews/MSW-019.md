## Wave 3 — Accessibility

Reviewer: independent agent with no memory of the implementation.

| # | View | Severity | Finding | Resolution |
|---|---|---|---|---|
| 1 | Audit log | must-fix | At 1024 px the reason and code columns were hidden. | All six columns remain at 1024 px with tighter padding and a 200 px reason column. At 640 px the table becomes labelled cards. |
| 2 | Settings and dialog | must-fix | Field borders were about 1.6:1 against the fill. | Added `--field-line: #847760` (at least 3.4:1 on every dark surface and 3.8:1 on light surfaces) to inputs, selects, secondary buttons, and switches. The light primary button has a 5.3:1 border. |
| 3 | Audit log | must-fix | At 640 px the table lost its headers and field labels. | Every cell now renders a visible `cell-label` (Time, Actor, Action, Subject, Reason, Code) in the card layout. |
| 4 | Inputs and search | should-fix | Input focus used a 1.2:1 outline. | Inputs now use the same 2 px text-colour focus ring as buttons, with an accent border. |
| 5 | Light primary buttons | should-fix | The amber fill had a 1.8:1 boundary against the card. | Light primary buttons have an `--accent` border (5.3:1). |
| 6 | Settings | should-fix | Help text was not programmatically associated. | `Field` help IDs and `aria-describedby` are set for each input; `Toggle` uses a generated description ID. |
| 7 | Settings | should-fix | Theme choices used ARIA radio roles without arrow keys or a non-colour selected marker. | Native radio inputs now use the browser radio group, with a visible check icon. |
| 8 | All views | should-fix | A view change left focus on the nav button and did not announce the new page. | The new `h1` receives focus and `document.title` updates. Loading wrappers use `role="status"` with a hidden loading sentence. |
| 9 | Toasts | should-fix | Toasts vanished after 4.2 s. | Toasts last 8 s, pause on hover and focus, and use `role="alert"` for failure text. |
| 10 | Toggles and toast close | nit | Targets were 44×24 and 26×26. | The switch has a 44×44 hit area; the toast close is 44×44. |
| 11 | Sidebar | nit | Disabled tools relied on a title tooltip. | The SOON chip is larger and brighter; the nav item still explains itself in its title. This is accepted for the shell milestone. |

The reviewer checked and passed: skip link, dialog focus trap/restore, button focus rings, landmarks and headings, table caption and column scopes at 1024, status text, error `role="alert"`, reduced motion, 200% mission layout, and 40 px controls.
